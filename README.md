# Voicemeeter-Potato-
Voicemeeter Potato注册
【使用须知】
1. 本注册工具不能删除。请先把它放到 Voicemeeter 程序文件夹里
   （默认 C:\Program Files (x86)\VB\Voicemeeter），再点“一键注册”。
2. 注册后会替换 桌面 / 开始菜单 / 开机自启 的快捷方式，并创建开机任务，
   完全接管原版启动方式。
3. 直接运行原版 voicemeeter8x64.exe 依然是未激活状态，必须通过本工具启动。
4. 注册工具一旦移动或删除，快捷方式和开机任务会失效，需要重新注册。
5. 本机没有安装杀毒软件，未做杀软兼容性测试；若被杀软拦截或报毒，请自行判断风险。
